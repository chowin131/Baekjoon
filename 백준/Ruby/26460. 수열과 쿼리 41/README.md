### 문제 설명

<p>길이가 $N$인 수열 $A_1, A_2, \ldots, A_N$ 이 주어진다. 이 때, 다음 쿼리를 수행하는 프로그램을 작성하시오.</p>

<ul>
	<li><code>0 l r x</code>: $l \le i \le r$ 에 대해 $A_i = max(A_i, x)$ 를 배정한다.</li>
	<li><code>1 l r</code>: $max(0, max_{l \le u \le v \le r} (\sum_{i = u}^{v} A_i))$ 를 출력한다.</li>
</ul>

### 입력 

 <p>첫 번째 줄에 수열의 길이 $N$ 과 쿼리의 수 $Q$ 가 주어진다.</p>

<p>두 번째 줄에 수열 $A$ 의 원소 $A_1, A_2, ..., A_N$ 이 주어진다.</p>

<p>이후 $Q$ 개의 줄에 위에서 설명한 것과 같은 쿼리가 주어진다.</p>

### 출력 

 <p>모든 <code>1 l r</code> 형태의 쿼리에 대해 정답을 한 줄에 출력하라.</p>
